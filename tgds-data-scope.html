TGDS Data Scope Controls

Open CSV
Choose the CSV to monitor. Data Scope asks Chromium to start in Downloads when supported. With a persistent file handle, the same file can be reread as another process changes it.
Start Monitoring
Begins periodic rereading of the selected CSV using the Refresh interval.
Stop
Stops automatic rereading. The currently displayed data remains visible.
Read Now
Immediately rereads the selected file once without waiting for the next scheduled poll.
Pause Display
Freezes the graph for inspection while TGDS continues polling and collecting samples. Resume returns to the current live view.
Live Statistics
Shows Current, Min, Max, Average, change from the prior sample, and rate per second for each selected series.
Crosshair
Move the pointer over Line Scope or Scatter to inspect the nearest sampled system time and the series values at that point.
Source Change Markers
Line Scope and Scatter show subtle vertical markers when TGDS detects that the underlying CSV file changed. Poll time continues even between source changes.
Full Screen
Expands the graph area using the browser Fullscreen API and includes the synchronized Live Statistics panel below the graph. Use the button again or Escape to return.
Pop Out Graph
Opens the live graph in a separate window with its own synchronized Live Statistics panel. Opens a large graph-only window. Monitoring remains owned by the main page, so opening or closing the pop-out does not stop the feed.
Visualization
Line Scope connects samples over time. Scatter shows each sample as a point. Equalizer shows recent time positions as groups of vertical bars.
Leading Edge
Choose where the newest live sample appears. Right puts both the newest data and the Y-value scale on the right edge; Left puts them on the left. X-axis ticks always show the current system clock time, with the newest time highlighted at the leading edge.
Refresh
How often Data Scope rereads the file while monitoring, from 250 ms through 10 seconds.
Display Points
Maximum number of recent samples shown in Line Scope and Scatter. Older samples age out of the visible window.
Equalizer Slots
How many recent time positions the Equalizer keeps visible at once.
Series to Monitor
Every numeric or recognizable date/time CSV column is discovered automatically as a live series, including a source column named timestamp. System time still supplies the X axis. Date/time series are converted to epoch seconds internally and marked [time] in the legend. Use the checkboxes to show or hide individual series.
Recommended live test: run tgds-live-feed.bat and open the generated tgds-live-data.csv. TGDS samples the latest row on each poll and plots it against system time.
